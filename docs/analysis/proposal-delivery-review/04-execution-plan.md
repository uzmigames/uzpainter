## Order and parallelism

Stage 0 is one message to the owner and blocks nothing. Stage 1 is the critical path. Stage 2 applies at once. Stage 4's spikes need no Painter and can run in parallel with stage 1, one GPU run at a time (CLAUDE.md test budget). Stage 3 starts when G1 is written and the stage 0 Belt answer arrives. Stage 5 is small and can go anywhere.

## What this plan does not change

Exact equality stays the default. Every divergence still needs a signed exception. The preview stays outside parity evidence. The clean-room rules and the private oracle store stay as they are. No task, golden or exception is created or edited by this analysis.
