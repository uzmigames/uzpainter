## 8. Known failures and fixes

| Failure | Cause | Fix / rule | Status | Source |
|---|---|---|---|---|
| Painter bake refused texture sets without UV tiles ("no enabled UV tiles") | MCP preflight/`start_bake` required a non-empty tile list even for non-UDIM sets | Local patch: only require enabled tiles when `all_uv_tiles()` is non-empty | Fixed (patch) | F — `Docs/Pipeline/MCP/substance-painter-mcp-local.patch`; `Docs/README.md` |
| Bake ran on the old mesh after a reload | Status read from the previous job; existing backup blocked reload | Pass `overwrite_backup: true`; poll the current `job_id`; reload → rebake mesh maps → resync masks | Procedure | F — `Docs/Pipeline/Licoes/operacao-recarga-job-id.md`; `.claude/skills/pintura-pbr/SKILL.md` → "Recarga de malha" |
| New islands changed curvature everywhere in a set | Painter's automatic curvature range is per texture set | Re-bake curvature with fixed bounds found by iteration against the old map; record bounds | Validated on body v6 | F — `.claude/skills/pintura-pbr/SKILL.md` → "Carrying paint onto a changed mesh"; `SM/00-Corpo/report.json → painting_v6` |
| AO = 0 read as occlusion; dark spot on hat crown | Ray misses (cage/ray too short) | Second, wider AO bake only on missed texels; real tears become their own mask | Validated | F — `Docs/Pipeline/Licoes/pintura-ao-falhas-de-raio-definicao.md` |
| AO bake could not see the high | Collections excluded from the view layer | `garment_blender_io.py extract` re-enables collections/layers before baking | Fixed in tool | F — `.claude/skills/pintura-pbr/REFERENCE.md` → "Armadilhas desta rodada" |
| `--repair-min-z` altered used surface, wrapped with `np.roll`, kept no RAW (144,983 texels on belt) | Low Z treated as invalid; centre-only masks | Keep RAW + masks; repair padding only; conservative SAT coverage; count every fallback | Tool fixed; per-asset revalidation pending | F — `Docs/Pipeline/Licoes/bake-raw-cobertura-estagios.md` |
| Black (Z < 0) normal texels on hidden faces / tab interiors | Rays starting inside another part of a fused high; twisted low rows | `--parts`, `--hidden-mask`, `cage_fill`; common row heights across a panel | Validated | F — `.claude/skills/pintura-pbr/SKILL.md` → "Couro com metal: 23-Cinto"; `Docs/Pipeline/Licoes/low-linhas-comuns-por-painel.md` |
| 2,641 black RGB16 texels in a Painter re-export of the hat normal | Coincident opposite faces with zero corner normals/bitangents in the saved low (NaN normals in Painter export) | Fix geometry/normal basis in a derivative; assert finite non-degenerate TBN before bake/export | Diagnosed; production fix pending | F — `Docs/Pipeline/Licoes/bake-normais-tbn-por-canto.md`; `Docs/analysis/skeletal-mage-review/05-auditoria-spp-10-13-20261007.md` |
| Masks/lookups wrong after vertices moved | Blender re-triangulates ngons when vertices move | Bind masks and lookups to the evaluated triangulation of the exact saved file | Rule | F — `Docs/Pipeline/Licoes/bake-triangulacao-avaliada-salva.md` |

## 9. Gate after the bake

**F** — Render the low with the baked normal and the high in a neutral material (no paint, no procedural weave), in the views required by `AGENTS.md`; check silhouette, layers, openings, folds, details and projection artefacts; record `low_high_fidelity = pass` only if visually identical or very close; revalidate after any geometry/UV/triangulation/bake change (`.claude/skills/pintura-pbr/SKILL.md` step 4 "Portão após o bake"; tool `Docs/Pipeline/Render/render_fidelity_pairs.py`, neutral grey linear 0.18, roughness 0.5, MAE and silhouette IoU per view). Numbers support but never replace the visual check (`AGENTS.override.md` → "At each gate").
