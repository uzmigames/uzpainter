## 2. Implementation
- [ ] 2.1 Discover each generator's parameter names, ranges and labels through the documented `Property` API and record them with provenance
- [x] 2.2 Implement the Curvature, Position, World Space Normals and Ambient Occlusion generators reading mesh maps by usage
  - Note (2026-10-20, decision 329): `src/procedural/generators.{h,cpp}`: four `IHlslFamily` families registered from their library records (`RegisterGeneratorFamilies`), each one kernel pass shaping one mesh-map signal (signed curvature, position axis, signed world-normal axis, occlusion 1 - ao) with Peachey's boxstep and smoothstep, plus a CPU reference from the primitive library. Mesh maps are bound by usage from the texture set (`BindMeshMaps`, `GeneratorRequest`, `SetGeneratorEffect`); every map has the output's resolution (`JointRefusal`). Evidence: `tests/procedural/test_proc_generator_families.py` `test_mesh_map_generators_follow_their_formulas` (25 checks, CPU), `test_generator_kernels_compile` (DXIL + SPIR-V) and `test_generators_on_dx12_equal_the_cpu_reference_and_repeat` (DX12 bit-exact, whole and by tile (16 DX12 cases; the file: 16 passed in 412 s)); log `tmp/scratch/proc-gen/e-pytest-generators.log`.
- [x] 2.3 Implement Dirt and Metal Edge Wear from curvature/AO edge and cavity detection plus the shared noise and morphology primitives
  - Note (2026-10-20, decision 329): Dirt (cavity clamp(1 - 2c) and occlusion, after Miller 1994, Hsu and Wong 1995) and Metal Edge Wear (convex edges less occluded wear, after Paquette, Poulin and Drettakis 2001): three passes each, the base mask, a disk dilation (`prim::Dilate` / HLSL `Morph`) and an fBm Perlin 2002 breakup over the position map seeded by the request, then a boxstep. Evidence: `tests/procedural/test_proc_generator_families.py` `test_dirt_and_edge_wear_follow_their_formulas` (13 checks, CPU: formulas at the defaults and an edit, seed dependence, monotone spread, edge detection equal to the Curvature generator, tiles) and the DX12 case; log `tmp/scratch/proc-gen/e-pytest-generators.log`.
- [x] 2.4 Implement Mask Builder (Legacy) and Mask Editor
  - Note (2026-10-20, decision 329): Mask Builder (one of five sources boxstepped, a boxstepped noise mask mixed in, disk growth or erosion; three passes) and Mask Editor (a weighted sum of six mesh-map terms boxstepped and optionally inverted; two passes, five mesh maps). Evidence: `tests/procedural/test_proc_generator_families.py` `test_mask_builder_and_mask_editor_follow_their_formulas` (15 checks, CPU) and the DX12 case; log `tmp/scratch/proc-gen/e-pytest-generators.log`.

  - Note (2026-10-20, decision 329): the domain half is done: the eight records `assets/procedural/records/generator.*@1.json` (Curvature, Position, World Normal Direction, Occlusion, Cavity Dirt, Edge Wear, Mask Builder, Mask Editor) declare their parameters (UzPainter's own names and ranges, each `low`/`high` pair ordered by 2^-8), the `any_u32` seed policy, the mesh classes `sphere`/`bevelled-cube`/`garment` on one UV tile, the mesh maps they read by usage (1024/2048/4096, u8 or u16, `Raw`, 1 or 3 channels) and the output (one f32 `linear` channel at 1024/2048/4096), all with status `unavailable`, no corpus and no alias. Evidence: `tests/procedural/test_proc_generator_families.py::test_generator_domain_is_declared_before_calibration` (8 cases, the harness's `Domain` parses each) and `test_no_alias_names_a_generator_family`; the shipped library loads in C++ (`tests/procedural/test_proc_asset_library.py`, 17 passed). - [ ] 3.1 Tier 2a for every generator on unit sphere, bevelled cube and hat v6 low × {1024, 2048, 4096} × parameter sets × seeds against private goldens (the calibration set), and on the held-out set reserved in 2.7, reported separately

  - Note (2026-10-20, decision 329): `BindMeshMaps` fails (`request_failed`) naming the map for a missing binding, a binding marked invalid (its report quoted), an image the resources lack, an image of another size, channel count or sample type, and a non-square set; the CPU and candidate lanes fail on a missing or wrong-size raster before any work; a reference that binds a mesh map itself is refused. Evidence: `tests/procedural/test_proc_generator_families.py` `test_missing_or_invalid_mesh_map_fails_loudly` (16 checks, CPU); log `tmp/scratch/proc-gen/e-pytest-generators.log`.
- [x] 3.3 DX12 repeatability: identical bytes across two runs for each generator
  - Note (2026-10-20, decision 329): Every generator at its defaults and one edited set (16 cases) evaluated twice on DX12 gives identical bytes, and equals its CPU reference bit for bit, whole and by border tile. Evidence: `tests/procedural/test_proc_generator_families.py` `test_generators_on_dx12_equal_the_cpu_reference_and_repeat` (16 DX12 cases; the file: 16 passed in 412 s); log `tmp/scratch/proc-gen/e-pytest-generators.log`.
- [x] 3.4 Domain-refusal test: a parameter, seed, mesh-map input and resolution just outside the declared domain each raise `UnsupportedProcedural{reason: "outside certified domain"}` before mutation, with nothing clamped or substituted
  - Note (2026-10-20, decision 329): `SetGeneratorEffect` on Dirt refuses 12 requests just outside the domain (a parameter one ulp above and below its range, a value outside its set, the joint constraint, a seed of 2^32, a mesh class, a missing mesh map, a half-float or another-colour-space mesh map, a mesh map at another resolution than the output, output resolutions 512 and 8192) with `outside certified domain` naming the field, before `submit` is called: the revision and the project are unchanged, and the candidate lane evaluates nothing. Inside the domain the uncertified family is refused (`family not certified`); an admitted edit commits the reference with no mesh map in it. Evidence: `tests/procedural/test_proc_generator_families.py` `test_requests_just_outside_the_domain_are_refused_before_mutation` (CPU); log `tmp/scratch/proc-gen/e-pytest-generators.log`.
