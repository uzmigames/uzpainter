# Changelog

All notable changes to UzPainter are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

No source code exists yet. The entries below record the documentation foundation
that engineers and AI agents build UzPainter from; start with the reading order in
`docs/README.md`. The build contract is `docs/`; the files under `docs/analysis/`
are historical evidence and are not implementation inputs until the approved-source
index (work package `P0-SOURCES` in `docs/dag.md`) clears their exact revision.

## [Unreleased] - 2026-10-10

### Added

- Compositor sources and UV projection (task `phase1.8_compositor-sources-projection`): uniform and bitmap fill sources, UV projection, Painter's hardware sRGB8 conversion tables, exact float32 bilinear rounding, Height stored as 2t−1 over base 0 in all templates; tile-cache key now includes the grid size (stale-tile bug fixed); two bilinear differences moved to `phase1.9_compositor-resample-gaps`.
- P1-MESH accepted (task `phase1.7_mesh-loader`) and store inspect/census (task `phase1.7_store-inspect-census`, awaiting hosted CI): mesh loader integration evidence in `parity/reports/phase1/mesh-loader.md`; `inspect` output, portable bundle codec and size census against the 10 % `.spp` budget in `parity/reports/phase1/store-inspect-census.md`.
- Save, retention and compaction (task `phase1.6_store-save-retention`, awaiting hosted CI): save/save-as/save-as-copy/revert/close, named and previous checkpoints, retention of current + previous + last 50 mutations + protected checkpoints (decision 024), compaction via `VACUUM INTO` on a copy with atomic rename, single-owner `.uzp.lock` sidecar; fault-injected kills at every compaction step.
- Mesh reload (task `phase1.6_mesh-reload`, awaiting hosted CI): reload keeps the layer stack, re-derives the old mesh from stored bytes, classifies texels (including `removed`), flags dependent mesh maps and nodes, refuses renames without a material mapping, identical reload is a no-op.
- Mesh tangents and certificate (task `phase1.5_mesh-tangents-certificate`, awaiting hosted CI): MikkTSpace per-object tangents with PerVertex (default) and PerFragment frames reproducing the P0-NORMAL residuals; CPU mesh certificate (normals, tangent frames, coincident opposite faces, UV range/overlap/islands/density) with pass/warn/fail.
- Compositor tile DAG (task `phase1.5_compositor-tile-dag`): `(stack, channel, tile)` DAG with subtree-hash invalidation, VRAM admission with LRU, evaluation order and generated blend kernels; 28 authored templates in `assets/templates/`; Tier 0 base values, template channel sets, blend order and group goldens exact on CPU and GPU; 23 separable blend modes × 9 formats GPU == CPU bit for bit.
- Mesh import and project store (tasks `phase1.4_mesh-importers`, `phase1.4_store-container-operations`, `phase1.5_store-planes` in progress): own OBJ parser, ufbx and fastgltf (+simdjson) loaders; Painter's polygon split measured and matched exactly (fan from the last corner, `parity/semantics/polygon-triangulation.json`); unset tangent mode now PerVertex (decision 031); SQLite 3.54 + zstd 1.5.7 project container with fault-injected commits, immutable raster plane versions and chunk roots; compositor tile DAG work in progress.
- P1-CORE accepted (task `phase1.4_render-core-layer`): Tier 0 meshes rasterised against a double-precision reference, compile→dispatch→drain chain bit-exact, render headers free of DX12/DXGI/Vulkan includes, vendoring check also builds `render-tests`.
- UV raster and image passes (tasks `phase1.3_core-uv-raster`, `phase1.3_core-image-passes`): GPU rasterisation into UV space with exact conservative mask and position/normal/tangent/island/material/triangle buffers; dilation (jump flood), resampling (Nearest, Painter fixed-point Bilinear, Box) and mips with sRGB/normal/alpha-coverage modes, each matching an independent CPU reference exactly. P1-DOCMODEL integration (`uzp_core.lib`, integrated round trip, pinned digests) awaits the hosted CI run.
