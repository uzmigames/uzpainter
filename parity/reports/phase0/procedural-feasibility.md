## 1. Go / no-go for `phase3.3_procedural-families` (P3-PROC)

Rule (Q1, decision 017): an asset is **go** only when its prototype equals both oracle recordings on every evaluated case (max |Δ| 0) and the oracle is stable; any non-zero residual is a candidate exception or gap, never equal, and makes the asset **no-go** for exact parity. A family is go only for its go members.

| Family | Asset (compatibility alias) | Cases | Equal cases | Worst max \|Δ\| | Prototype status | Verdict |
|---|---|---|---|---|---|---|
| mesh-map generators | Position | 6 | 6 | 0 | exact | **go** |
| mesh-map generators | Metal Edge Wear | 8 | 1 | 65535 | calibrated | **no-go** |
| smart materials | Leather Damaged | 2 | 0 | 19149 | calibrated | **no-go** |

Per family: **mesh-map generators** — go for Position (the gradient generator from the Position map is reproduced on every evaluated case, including a calibrated balance/contrast step). No-go for Metal Edge Wear: it is equal only where the result saturates (sphere, no grunge); on the rounded cube without grunge (boundary-a) the edge falloff of the prototype differs, and every case with grunge differs over a large share of texels because a clean-room seeded noise does not reproduce Painter's grunge texel for texel (the fit drives the grunge share towards 0). The **grunges and noises** family it relies on is therefore no-go for exact parity on this evidence. **Smart materials** — no-go for Leather Damaged: the independently designed stand-in matches the metalness (0) and normal (flat) channels but differs on every texel of base colour, roughness and height, and Painter's preset structure is not publishable (05 §3). The no-go assets stay visible capability gaps (05 §5) unless the owner approves exceptions with the residuals below as evidence.

## 2. Scope

- **Generators selected (task 2.2)** from the 05 §3 mesh-map generator list: **Position** (a deterministic gradient from the Position map) and **Metal Edge Wear** (edges from Curvature, seeded grunge, AO masking). Together they bracket the family: a closed-form generator and a noise-driven one. **Leather Damaged** is the smart material.
- **Evaluated subset of the 05 §6 matrix:** meshes {unit sphere, rounded (bevelled) cube} x resolution {1024} x parameter sets {defaults, two authored boundary sets} x seeds {default, 1} (Metal Edge Wear). Not evaluated: the hat v6 low mesh, resolutions 2048 and 4096, each recipe's recorded parameter set; Leather Damaged at defaults only (a smart material exposes no parameters to `set_parameters`).
- **Fixtures:** `parity/fixtures/feasibility/` (UzmiGames-authored, Apache-2.0): two OBJ meshes and six analytic 16-bit mesh maps each (position, world-space normal, flat tangent normal, AO, curvature, thickness), assigned in Painter with `TextureSet.set_mesh_map_resource`, so residuals measure the generator, not a baker. Conventions: `tools/parity/feasibility/fixtures.py`.
- **Manifests:** one public manifest per golden under `parity/manifests/phase0/procedural-feasibility/` (a public manifest describes one golden, so the single file named in the proposal became this folder).
- **Parameters** were discovered through the documented `Property` API (private readback, task 2.3); only names, labels, ranges, the documented default values the prototypes start from (Property metadata, like the ranges) and the authored values appear here.
- **Comparison domain:** texels whose centre lies in a UV triangle, eroded by one texel. Texels outside it are export padding (`passthrough`), which Painter leaves undefined and which differs between recordings.

Comparison run: machine Bolado, Python 3.13.9, numpy 2.4.4, repository commit ac528dc plus the working tree of this task, Painter build of the oracles `12.1.0+js-api.1.1.20`.
