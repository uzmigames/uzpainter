# Approved-source index

Work package P0-SOURCES (`docs/dag.md`); requirements CLR-01, CLR-02, CLR-04, LIC-03 (`docs/prd.md`); policy `docs/licensing-and-clean-room.md` (decision 002, as updated by decisions 018, 021 and 027). This file lists every source an implementer may use and every source that is off-limits. A source that is not listed as approved here is not an implementation input. A reviewer rejects a change whose provenance names a source missing from the approved part or listed in the quarantine.

Audit of 2026-10-10 (task `phase0.1_approved-source-index`). Reviewer of every entry: **Claude (clean-room audit agent), 2026-10-10**; the owner may revoke any clearance by a recorded decision.

## How to read and maintain this index

- **Entry fields.** ID; identifier (title and edition, URL or path); category; exact revision or hash where the source is a file; licence where code may enter the build; cleared scope (what it may be used for); `Cited as` (the forms in which the docs name it); reviewer.
- **Public web pages** carry their public URL and the retrieval date. Adobe's documentation shipped with Painter is identified by its public URL; the install path (`PAINTER\resources\…`, with `PAINTER` = Painter 12.1.0's install folder on the owner's machine) is listed only as the form the architecture uses to cite it.
- **UzmiGames files** carry repository, path, the commit that last changed the path and the git object hash at that commit (`git -C <repo> log -1 --format=%H -- <path>`, `git -C <repo> rev-parse <commit>:<path>`). The object hash fixes the content; a later revision is a different source and needs its own entry.
- **Historical analyses** (`docs/analysis/`) are cleared by exact revision: the git blob hash of the audited content and the commit it was audited at. Only that blob is approved. When the file changes, the new revision is uncleared until it is audited and its row updated. The blob hash survives the history recreation of decision 027; the commit column is re-pinned then. The sanitisation record (`docs/analysis/clean-room-redactions.md`) is not a clearance.
- **Citations.** A document may name a quarantined source only in a sentence that forbids it ("never", "not opened", "off-limits", …). It may name an uncleared analysis only as `historical context` — a pointer to where an argument was made, never a source of facts.
- **Checks.** `python -m tools.sources.check` runs the citation check (every source cited by `docs/architecture/*.md`, `docs/prd.md`, `docs/roadmap.md` and `docs/dag.md` resolves to an approved entry; none is quarantined) and the revision check (every cleared analysis blob exists in the history and equals the file at its commit; UzmiGames objects resolve in their repositories). Tests: `tests/sources/`.
