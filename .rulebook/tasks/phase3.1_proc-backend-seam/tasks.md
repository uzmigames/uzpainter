- [x] 2.2 Implement the `HlslBackend` host: family registration, generated HLSL compiled through the render core with `precise` arithmetic, content-hash kernel cache
  - Note (2026-10-19): `src/procedural/hlsl_backend.{h,cpp}`. Families register per pinned asset (a second registration and a non-float32 output domain are refused). Each pass is a generated HLSL body over a fixed wrapper, compiled through the engine's `KernelCache` (DXIL or SPIR-V, `-Gis`, content-hash key). Parameters travel in a structured buffer and the seed in a root constant, so edits reuse the kernel. Passes chain on the GPU, then the last pass is read back. A CPU reference lane and a diagnostic candidate lane exist; the seam never selects the candidate lane. Missing or invalid image inputs fail loudly. Evidence: `kernels` (10 kernels, both targets, NoContraction in SPIR-V, cache hits) and `gpu` (DX12). The host writes float32 only; quantised outputs belong to the families that are fitted to them.
- [x] 2.3 Implement the shared primitive library (Perlin 1985/2002, simplex, Worley, fBm, morphological and blur operators) with a provenance note per primitive
  - Note (2026-10-19): `src/procedural/primitives.{h,cpp}` (CPU reference) and `shaders/proc_primitives.hlsli` (mirror). The library has an integer-computed correctly rounded square root, pcg3d hashing, Perlin 1985 and 2002, 3D simplex (Gustavson), Worley F1/F2 (three metrics), fBm, dilation and erosion (square or disk), and the separable box and Gaussian blur. Subnormal results are flushed explicitly on both sides, and nothing uses division, hardware sqrt or transcendentals. Provenance per primitive: `src/procedural/primitives.provenance.json`, public papers, books and standards only.
